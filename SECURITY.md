# Security

Do not open issues containing API keys, private source URLs, passwords, tokens, private keystores, app database exports or completed .env files. Report suspected credential exposure privately through the repository owner's profile contact options.

Credentials are configured on-device and stored encrypted. Official signing material is maintained separately and never belongs in repository files or release assets. The optional Linux helper requires its own token and should remain on trusted local/VPN connectivity or properly secured HTTPS.
