# Changelog

## 1.0.0

The current standalone native Android application replaces the earlier web/Capacitor project on the main branch.

- Optional onboarding for Jellyfin, TorBox and source providers.
- Discovery, ranked trending/anticipated shelves, watchlist and upcoming releases.
- Passive Jellyfin playback tracking, viewing history, compact insights and monthly calendar.
- Compact Jellyfin/TorBox libraries, real scan progress, collections/versions and safe torrent management.
- Torrentio, AIOStreams and Torznab/Prowlarr with strict TorBox cached-only Find Sources.
- Zurg WebDAV browsing, optional STAK-approved library filtering and media quality inspection.
- Cinematic Nothing-style Compose UI with glass, motion, haptics and predictive back.

Application ID remains app.stak.nativeapp.parity; versionCode 47 keeps updates compatible with earlier development builds. Private signing and user credentials are excluded from source.
