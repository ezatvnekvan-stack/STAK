# STAK 1.0.0

The requested pre-Cinema STAK baseline, preserving the complete application from `b433c7ca3c69c37208be3dd8e508e8d408ddee8f`.

Includes the earlier UI, watched-date tracking, Following calendar, source-picker and Jellyfin watched-state fixes. Excludes Cinema Explorer, Trailer Channel, Series Hub and the later industrial redesign.

The APK is the original verified build from successful CI run 39383424789, reused byte-for-byte. Version 1.0.0, Android code 38, package app.dmmstudio.cinema. No rebuild or application behavior change was made for this migration. Only repository documentation and the workflow manual default ref were adjusted.

Assets: STAK-1.0.0.apk, complete source ZIP, SHA256SUMS.txt and APK_CERTIFICATE.txt.

The APK is debug-signed with its original certificate. Existing installations require a matching certificate for an in-place update; do not uninstall or clear data to work around a mismatch. Physical-device and live private-provider verification are not claimed.
