## Data/source limitations

Adding an episode/release to TorBox does **not** copy it into Jellyfin. Jellyfin requires a separately configured server download/import workflow. Playback remains external; trailers keep the existing provider-controlled embedded flow and fallback. No VLC or new playback engine/provider is introduced.

Episode synopses use existing TMDb/Cinemeta metadata; episode IMDb scores use Cinemeta where supplied or an optional configured OMDb episode lookup. Unavailable scores stay unavailable, and TMDb episode scores are not shown. Identity-based deduplication cannot safely merge unmatched records with neither provider IDs nor a shared Jellyfin presentation identity; names alone are insufficient. Scan observations still cover the latest 30 items, not a complete server import log. Cached-only sources require valid TorBox credentials and a successful cache check.

Native refresh hints, reduced-motion preferences and bounded caches remain. The ambient layer is a single static artwork layer, not per-poster processing. No claim of instant provider responses, measured 90/120 FPS, physical Android testing or live credentialed-provider success is made.
