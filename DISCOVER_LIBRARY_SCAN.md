# Android 14.5 — Discover search, collections and Jellyfin library scan

## Completed requests
- Discover starts with the exact existing Home search component: debounce, Movies/Series/All filters, relevance ordering, pagination, error handling and Details navigation are shared.
- Search results and their loading skeleton use four columns at phone widths. Compact text/cards fit 360px; media-card touch area remains the whole poster. Discovery collection results also use four columns.
- Home no longer renders its top Jellyfin library summary. Saved Home sections remain untouched.
- Jellyfin's library header includes a monochrome Jellyfin-shaped logo, actual per-user movie/show counts and media-file GB. File sizes are read through authenticated native requests, not guessed from runtime or torrent sizes. Alternate versions count; paths are deduplicated; missing sizes/pages show a partial total rather than a fictional full size. Calculation is paginated (250 items/request, bounded at 50,000 items), cancellable, cached for 15 minutes and manually refreshable. This covers user-accessible movie/episode media, not artwork, music, inaccessible libraries or server disk overhead. Full-library total may be unavailable if the server omits MediaSources.Size.
- Admin scan opens an animated Nothing dialog with an indeterminate waiting bar or the actual Jellyfin RefreshLibrary task percentage, queued/running/cancelling/verifying states, accurate failures and retry monitoring. A new LastExecutionResult is required before declaring completion; old Idle results never count as a successful new scan. Closing the dialog does not stop the server. Server changes/unmount cancel local monitoring. Background polling pauses while hidden; five-minute monitoring timeout is explicitly unconfirmed, never fake success.
- After confirmed completion, show net movie/show count changes and newly observed titles from before/after latest-30 snapshots. This is labeled as observed library changes, not a complete per-file scan import log. New episodes may not change series counts. If task permissions/status are unavailable, say completion/additions cannot be confirmed. Checking status does not issue another scan.
- Discover Collections & universes supports actual paginated TMDb collection and keyword search. MCU expands to “Marvel Cinematic Universe”; no universe membership is hardcoded. Official movie collections open their actual parts; universe/keyword results browse actual tagged movies or series according to the Discover type, with pagination and explicit coverage limits. TMDb collection results and keyword catalogs are labeled separately. A TMDb key is required; there is no fake MCU ranking or unlicensed data source.
