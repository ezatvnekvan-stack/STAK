## GitHub release delivery
The existing full validation workflow remains mandatory. A separate publish job runs only after successful verification for this same-repository stak-nothing-polish PR branch. It receives contents:write solely to fulfill the explicit request to publish APKs to Releases; the build job remains contents:read. It checks the packaged ZIP and APK, publishes a prerelease tag tied to the exact feature commit, and uploads STAK-debug.apk, STAK-Android-source.zip and SHA256SUMS.txt. Main is not changed or merged. No tokens or binaries are committed. The final PR links the confirmed release and build after they exist. GitHub login is required for this private repository.

This remains a debug preview. In-place updates require the original signing certificate. If Android reports a signature mismatch, do not clear data/uninstall to work around it; build with the original key. No physical Android/emulator/live-provider/actual FPS claim is made.
